# ESP32 Radar Tracker 1.1.34

Полная папка исходников прошивки 1.1.34 для LILYGO TTGO T-Display (классический ESP32, ST7789 240×135). Основа — версия 1.1.33.

## Сборка в Arduino IDE

1. Откройте `ESP32_Radar_Tracker_1.1.34.ino` из этой папки.
2. Выберите плату **ESP32 Dev Module** (ESP32 Arduino core 3.3.12).
3. В `TFT_eSPI/User_Setup_Select.h` включите профиль `TFT_eSPI_Setup25_TTGO_T_Display.h`.
4. Используйте TFT_eSPI 2.5.43.
5. Нажмите Verify/Compile.

Все файлы `.cpp`, `.h` и `Version.h` находятся рядом со скетчем. LD2401 и LD2450 используют общий UART1: GPIO27 RX, GPIO26 TX, 256000 бод; одновременно подключается только один датчик.

В 1.1.34 добавлены независимые 60-секундные линии графика для T1/T2/T3, история координат целей и более заметные синие следы движения на веб-радаре и TTGO.

Полная компиляция Arduino IDE и проверка на физическом TTGO для этой публикации не подтверждены.
