# Изменения прошивки 3.0.12

- Продолжение порта LD-Radar для ESP32-C3 SuperMini + ST7735 160×128.
- Исправлена анимация веб-радара: каждый кадр использует последние данные датчика, а не пустой набор.
- Отдельная визуализация сектора присутствия LD2401 и координатных целей LD2450.
- Уменьшено использование DRAM: передача framebuffer блоками SPI без второго полного буфера.
- История шлейфов оптимизирована: запись точки раз в 333 мс, до 5 минут.
- Сохранены настройки Wi-Fi, журнал, CSV, фильтры дальности и зоны тревоги.
