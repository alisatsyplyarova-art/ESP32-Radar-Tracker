ESP32 Radar Tracker — TTGO T-Display + HLK-LD2401 + HLK-LD2450
Version 1.0.019

Проект объединяет два независимых UART-драйвера:
- LD2450: координаты X/Y и до трёх целей для секторного радара (примерно 120° по области обнаружения датчика).
- LD2401: состояние присутствия/движения и дистанции; этот датчик не выдаёт координаты X/Y и не рисуется как отдельная точка на карте.

Драйверы работают независимо: отсутствие данных одного датчика не останавливает опрос второго. Экран, цели, кнопки, настройки и диагностика сохранены из исходного модульного проекта.

Ограничение: протокол LD2401 реализован по формату кадров, использованному в предыдущем скетче проекта (F4 F3 F2 F1, длина, payload 0x02, хвост F8 F7 F6 F5). На реальном экземпляре следует подтвердить baud rate и формат прошивки модуля по Serial Monitor. Компиляция в Arduino CLI в этой среде не выполнялась.
