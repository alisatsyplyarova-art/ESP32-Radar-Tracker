# ESP32 Radar Tracker 1.1.24

Проект для **LILYGO TTGO T-Display, классический ESP32, ST7789 240×135**. Подключается один датчик: HLK-LD2401 или HLK-LD2450.

## Возможности
- TFT-экраны RADAR, TARGETS, PRESENCE, DUAL, DIAG, SETTINGS.
- Стили ALIEN/CLASSIC, три темы, масштаб 0,5–6 м, яркость, следы целей.
- Автоматический выбор датчика с приоритетом LD2450 при валидной связи.
- LD2450: координаты X/Y и сопровождение до трёх целей.
- LD2401: присутствие/движение, расстояние и энергия; координат X/Y у него нет.
- Общий UART1: GPIO27 RX, GPIO26 TX, 256000 8N1. Только один датчик одновременно.
- Wi-Fi AP LD-RADAR, адрес http://192.168.4.1/, по умолчанию без пароля.
- Веб-панель, график 60 секунд, журнал до 80 записей, CSV, фильтр расстояния, зоны тревоги LD2450 и управление устройством.
- Копия TFT 240×135 в браузере: адаптивная ширина до 700 px, около 5 кадров/с.
- Новое в 1.1.24: веб-копия использует тёмно-голубую палитру веб-интерфейса. Физический TFT и его цвета не меняются.

## Сборка
Откройте `ESP32_Radar_Tracker_1.1.24.ino` в Arduino IDE. Требуются пакет плат Espressif ESP32 и библиотека TFT_eSPI от Bodmer. Выберите **ESP32 Dev Module**, включите Setup25 в `TFT_eSPI/User_Setup_Select.h`, выполните Verify/Compile и только затем Upload. Полная инструкция — `ИНСТРУКЦИЯ_ARDUINO_IDE.md`.

## Подключение
- LD2401: TX→GPIO27, RX→GPIO26, OUT→GPIO25 (необязательно), GND→GND.
- LD2450: TX→GPIO27, RX→GPIO26, GND→GND.
- Питание проверяйте по документации конкретного модуля.
- Зуммер GPIO32 подключать только через транзисторный ключ.

Исходники 1.1.24 опубликованы в GitHub. Компиляция Arduino IDE и проверка на физическом TTGO T-Display не подтверждены.

В заголовке радара ссылка «Журнал» ведёт непосредственно к журналу измерений.
