# ESP32 Radar Tracker 1.1.30

Полная папка скетча для LILYGO TTGO T-Display (классический ESP32, ST7789 240×135).

## Сборка в Arduino IDE

1. Откройте файл **ESP32_Radar_Tracker.ino** именно из этой папки.
2. Выберите плату **ESP32 Dev Module** (пакет Espressif ESP32 3.3.12).
3. В настройках TFT_eSPI включите профиль `TFT_eSPI_Setup25_TTGO_T_Display.h`.
4. Установите TFT_eSPI 2.5.43.
5. Нажмите Verify/Compile.

Все необходимые исходники `.cpp`, заголовки `.h` и `Version.h` находятся рядом со скетчем. Не открывайте старую неполную папку `firmware/ESP32_Radar_Tracker` из исходного архива 1.1.30.

## Датчики

LD2401 и LD2450 используют общий UART1: GPIO27 RX, GPIO26 TX, 256000 бод. Подключать одновременно только один датчик.

Версия: 1.1.30. Компиляция и проверка на физической плате в этой публикации не подтверждены.
