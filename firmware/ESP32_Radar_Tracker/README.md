# ESP32_Radar_Tracker

В эту папку помещаются основной файл `ESP32_Radar_Tracker.ino`, все связанные `.h` / `.cpp`, `VERSION.txt` и файл настройки TFT_eSPI. Не разносите части одного Arduino-скетча по отдельным подпапкам: Arduino IDE должна видеть их в общей папке скетча.

См. документацию в `../../docs/`.
