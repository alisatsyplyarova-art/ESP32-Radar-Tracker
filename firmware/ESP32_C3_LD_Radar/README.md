# ESP32-C3 LD-Radar

Отдельная ветка проекта для **ESP32-C3 SuperMini + платы дисплея 1.77" TFT**.

## Что подтверждено по фотографиям

- Контроллер: ESP32-C3 SuperMini.
- Плата дисплея подписана `1.77" TFT`.
- Интерфейс дисплея: SPI-сигналы `SCK`, `SDA`, `RES`, `RS`, `CS`, подсветка `LEDA`.
- Предполагаемое разрешение панели: 128x160.
- Контроллер ST7735/ST7735S пока не подтверждён маркировкой или тестом.
- На адаптере также выведены `GT_CS`, `GT_SI`, `GT_SO`, `GT_SCL`; назначение пока не подтверждено.

Подробная таблица позиций разъёма и ограничения C3: [hardware/ESP32-C3-SuperMini-1.77TFT.md](../../hardware/ESP32-C3-SuperMini-1.77TFT.md).

## Важно

Номера 1..14 на таблице адаптера — это номера контактов разъёма, а не GPIO ESP32-C3. По фотографиям не видны дорожки между этими контактами и площадками SuperMini. Поэтому GPIO-распиновка пока не назначена, чтобы не повредить плату и не создать конфликт TFT/UART.

## Следующие этапы

1. Установить соответствие 14 контактов адаптера GPIO/питанию SuperMini.
2. Подтвердить контроллер и ориентацию TFT, проверить тестовую заливку экрана.
3. Назначить отдельные UART GPIO для LD2401/LD2450.
4. Перенести логику радара, веб-интерфейс, фильтры, шлейфы и зоны тревоги.
5. Собрать Arduino firmware для ESP32-C3 и проверить на реальной плате.

Основная прошивка классического ESP32 в `main` не меняется.
