# ESP32-C3 LD-Radar

Отдельный порт проекта для **ESP32-C3 SuperMini + TFT 1.77" ST7735 160x128**.

Действующая начальная сборка находится в [firmware/ESP32_C3_LD_Radar_0.1.0](../ESP32_C3_LD_Radar_0.1.0/README.md).

## Подтверждённая распиновка дисплея

| Сигнал | GPIO |
|---|---:|
| GND | GND |
| VCC | 3.3V |
| SCK | GPIO4 |
| SDA / MOSI | GPIO3 |
| RES | GPIO2 |
| RS / DC | GPIO1 |
| CS | GPIO0 |

Экран устанавливается непосредственно на плату-адаптер SuperMini.

## Радар

LD2401 или LD2450 подключается отдельными проводами:
- TX датчика → GPIO20 (RX ESP32-C3)
- RX датчика ← GPIO21 (TX ESP32-C3)
- GND → GND
- UART 256000, 8N1; одновременно подключать только один датчик.

Классическая прошивка ESP32 в main не меняется.
