# ESP32 Radar Tracker 1.1.51

Полная папка исходников для LILYGO TTGO T-Display (классический ESP32, ST7789 240×135).

## Изменения 1.1.51
- Уменьшен шрифт значений карточек веб-интерфейса с 24 до 18 px.
- Для длинных статусов «НЕПОДВИЖНО» и счётчика «OUT / кадры / ошибки» установлен компактный шрифт 14 px и безопасный перенос строк.
- Изменения относятся только к веб-странице; шрифты TFT TTGO и отрисовка радара не менялись.
- Сохранено исправление JavaScript из 1.1.50.

## Сборка Arduino IDE
1. Откройте `ESP32_Radar_Tracker_1.1.51.ino`.
2. Выберите **ESP32 Dev Module** (ESP32 Arduino core 3.3.12).
3. В `TFT_eSPI/User_Setup_Select.h` включите профиль `TFT_eSPI_Setup25_TTGO_T_Display.h`.
4. Используйте TFT_eSPI 2.5.43 и выполните Verify/Compile.

LD2401 и LD2450 используют общий UART: GPIO27 RX, GPIO26 TX, 256000 бод; одновременно подключается только один датчик.

GitHub Actions проверяет JavaScript через `node --check` и собирает ZIP. Компиляция Arduino IDE и проверка на физическом TTGO/датчике отдельно не подтверждены.
