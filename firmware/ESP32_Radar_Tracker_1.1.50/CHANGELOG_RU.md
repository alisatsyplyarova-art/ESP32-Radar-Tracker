# Изменения версии 1.1.50

- Исправлена лишняя закрывающая скобка в JavaScript-выражении подсчёта rawMask в функции refresh().
- Исправление устраняет SyntaxError, из-за которого браузер не запускал веб-скрипт радара, графика, показателей и настроек.
- Проверка JavaScript добавлена в автоматическую упаковку: извлечение скрипта из RadarWeb.cpp и проверка `node --check`.
