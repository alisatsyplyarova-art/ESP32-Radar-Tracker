# ESP32 Radar Tracker 1.1.50

Полная папка исходников для LILYGO TTGO T-Display (классический ESP32, ST7789 240×135).

## Исправления 1.1.50
- Исправлена лишняя закрывающая скобка в JavaScript-счётчике rawMask на веб-странице LD2450. Ошибка блокировала запуск всего скрипта, включая радар, график и обновление показателей.
- Сохранены веб-координаты X/Y трёх целей T1–T3 под цветовой легендой.
- Сохранены атомарное применение фильтра расстояния, три дорожки сопровождения, тревожные зоны 1–6 м и работа с LD2401/LD2450.

## Сборка Arduino IDE
1. Откройте `ESP32_Radar_Tracker_1.1.50.ino`.
2. Выберите **ESP32 Dev Module** (ESP32 Arduino core 3.3.12).
3. В `TFT_eSPI/User_Setup_Select.h` включите профиль `TFT_eSPI_Setup25_TTGO_T_Display.h`.
4. Используйте TFT_eSPI 2.5.43 и выполните Verify/Compile.

LD2401 и LD2450 используют общий UART: GPIO27 RX, GPIO26 TX, 256000 бод; одновременно подключается только один датчик.

Проверка JavaScript выполняется в GitHub Actions через `node --check`. Компиляция Arduino IDE и проверка на физическом TTGO/датчике отдельно не подтверждены.
