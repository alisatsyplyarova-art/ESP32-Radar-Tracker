ПОДКЛЮЧЕНИЕ — TTGO T-DISPLAY CLASSIC ESP32

Общие правила: общий GND обязателен. RX на ESP32 подключается к TX датчика; TX ESP32 — к RX датчика. Проверьте уровни питания и UART по документации именно вашей платы датчика.

LD2450 (UART1):
- LD2450 TX -> TTGO GPIO27 (PIN_LD2450_RX)
- LD2450 RX -> TTGO GPIO26 (PIN_LD2450_TX)
- GND -> GND
- питание согласно маркировке/документации платы LD2450

LD2401 (общий UART1):
- LD2401 TX -> TTGO GPIO27 (PIN_LD2401_RX)
- LD2401 RX -> TTGO GPIO26 (PIN_LD2401_TX; как в рабочей v1.0.004)
- OUT -> TTGO GPIO25 (PIN_LD2401_OUT; необязательный диагностический сигнал)
- GND -> GND
- питание согласно документации модуля LD2401

LD2401 подключается по рабочей схеме из v1.0.004: TX→GPIO27, RX→GPIO26, OUT→GPIO25. LD2450 подключается по той же схеме: TX→GPIO27, RX→GPIO26. Подключайте только один датчик за раз: оба датчика используют GPIO27/26 и один UART1. UART установлен на 256000 8N1. Не подавайте 5 В на GPIO ESP32; питание датчика — по документации модуля.

Автоматический выбор датчика: подключите только LD2401 или только LD2450. Прошивка выберет датчик после получения корректных кадров; в Serial Monitor появится строка [AUTO] Selected sensor. Главный экран для LD2401 показывает присутствие/дистанцию, для LD2450 — координаты X/Y.


### Звуковое оповещение (версия 1.1.15)
Опционально подключите активный зуммер через транзисторный ключ к GPIO32 и GND с подходящим питанием. В веб-интерфейсе включите «Внешнее звуковое оповещение» и выберите зону 1/2/3 м. Выход включается только при реальной цели внутри зоны; в DEMO выход всегда выключен. Не подключайте зуммер/нагрузку напрямую к GPIO. По умолчанию опция выключена.


### Зоны обнаружения LD2450 (1.1.15)
В веб-панели доступны передняя центральная, левая, правая и задняя зоны. По умолчанию включена только передняя центральная. Зоны управляют тревогой, но не скрывают цели с экрана и карты. Для LD2401 разделение по направлению невозможно: используется тревога по расстоянию.
