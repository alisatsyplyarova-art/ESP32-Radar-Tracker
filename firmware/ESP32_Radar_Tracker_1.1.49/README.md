# ESP32 Radar Tracker 1.1.49

Полная папка исходников для LILYGO TTGO T-Display (классический ESP32, ST7789 240×135).

## Изменения 1.1.49
- Веб-фильтр минимальной и максимальной дальности применяется одной атомарной командой.
- На основном TFT-экране LD2450 полукруг радара смещён влево, справа постоянно отображаются координаты X/Y всех трёх целей T1–T3.
- Сохранены обработка отрицательной координаты Y, три дорожки сопровождения, тревожные зоны 1–6 м и фильтр дальности.

## Сборка Arduino IDE
1. Откройте `ESP32_Radar_Tracker_1.1.49.ino`.
2. Выберите **ESP32 Dev Module** (ESP32 Arduino core 3.3.12).
3. В `TFT_eSPI/User_Setup_Select.h` включите профиль `TFT_eSPI_Setup25_TTGO_T_Display.h`.
4. Используйте TFT_eSPI 2.5.43 и выполните Verify/Compile.

LD2401 и LD2450 используют общий UART: GPIO27 RX, GPIO26 TX, 256000 бод; одновременно подключается только один датчик.

Компиляция Arduino IDE и проверка на физическом TTGO/LD2450 для этой публикации пока не подтверждены.
