# Изменения 3.0.17
- Возвращена тонкая однопиксельная линия луча, без искусственного утолщения.
- Целевой интервал обновления дисплея уменьшен с 20 до 10 мс.
- SPI ускорен до 40 МГц; передача кадра оптимизирована блоками по 512 пикселей вместо 128.
- Угол луча пересчитывается по времени на каждом кадре; сохранено непрерывное движение туда-обратно для LD2401 и LD2450.
- Сохранены функции 3.0.16, включая восстановление домашнего Wi-Fi.

# Изменения 3.0.16
- Луч на ST7735 движется непрерывно туда-обратно без скачка в начале цикла для LD2401 и LD2450.
- Добавлено мягкое свечение: яркое ядро и приглушённые боковые линии.
- Частота обновления дисплея повышена до 50 кадров/с; частота SPI увеличена до 26 МГц.
- Сохранены автоматическое восстановление домашнего Wi-Fi и все функции 3.0.15.

# Изменения 3.0.15
- Добавлен автоматический повтор подключения к сохранённой домашней Wi-Fi сети без отключения точки доступа LD-RADAR-C3.
- Включено автоматическое восстановление STA-соединения; SSID и пароль продолжают храниться в Preferences.
- Статус и IP домашней сети обновляются в фоне.
- Луч LD2401 на дисплее ускорен и ограничен сектором 60°; веб-луч ускорен и сужен.
- Все функции 3.0.14 сохранены.
