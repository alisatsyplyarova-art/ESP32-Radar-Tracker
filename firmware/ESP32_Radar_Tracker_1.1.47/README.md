# ESP32 Radar Tracker 1.1.47

Полная папка исходников для LILYGO TTGO T-Display (классический ESP32, ST7789 240×135).

## Сопровождение целей LD2450

LD2450 может менять порядок трёх выходных слотов между кадрами. Прошивка сопоставляет все измерения со всеми активными дорожками одновременно, выбирая глобально лучшую комбинацию. Для каждой дорожки рассчитывается прогноз координат по оценённому вектору скорости X/Y. Это снижает вероятность скачков ID и объединения близких целей в одну дорожку.

При физическом пересечении людей или неоднозначных измерениях радара абсолютная гарантия сохранения ID невозможна.

## Сборка Arduino IDE

1. Откройте `ESP32_Radar_Tracker_1.1.47.ino`.
2. Выберите **ESP32 Dev Module** (ESP32 Arduino core 3.3.12).
3. В `TFT_eSPI/User_Setup_Select.h` включите профиль `TFT_eSPI_Setup25_TTGO_T_Display.h`.
4. Используйте TFT_eSPI 2.5.43 и выполните Verify/Compile.

Все исходники модулей находятся рядом со скетчем. LD2401 и LD2450 используют общий UART1: GPIO27 RX, GPIO26 TX, 256000 бод; одновременно подключается только один датчик.

Сохранены функции 1.1.46: тревога 1–6 м, четыре сектора LD2450, фильтр дальности и история следов до 300 секунд.

Компиляция Arduino IDE и проверка на физическом TTGO для этой публикации не выполнялись.
