# Изменения версии 1.1.47

- Переработано сопоставление трёх целей LD2450 между кадрами.
- Вместо жадного выбора ближайшей пары выполняется глобальный перебор допустимых назначений.
- Для каждой дорожки рассчитывается краткосрочный прогноз координат по вектору движения X/Y.
- Радиус сопоставления адаптируется к скорости и ограничен сверху.
- Сохранены тревожные зоны 1–6 м, настройки и история следов версии 1.1.46.

Ограничение: при физическом пересечении людей или неоднозначных измерениях самого LD2450 неизменность ID гарантировать нельзя. Компиляция и проверка на физическом TTGO в этой среде не выполнялись.
