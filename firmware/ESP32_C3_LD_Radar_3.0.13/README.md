# ESP32-C3 LD-Radar 3.0.13 — Direct SPI

Полная версия переноса LD-Radar на **ESP32-C3 SuperMini + TFT ST7735 1.77″ (160×128)**. Драйвер экрана реализован непосредственно через SPI и собственный framebuffer. Дуги радара сглаживаются субпиксельным рендерером. **TFT_eSPI не нужен.**

## Дисплей — подтверждённая распиновка

| Линия | GPIO |
|---|---:|
| GND | GND |
| VCC | 3.3V |
| SCK | GPIO4 |
| SDA / MOSI | GPIO3 |
| RES | GPIO2 |
| RS / DC | GPIO1 |
| CS | GPIO0 |

LEDA подсветки запитана от адаптера; отдельный GPIO не используется.

## Радар — UART

| Сигнал | ESP32-C3 |
|---|---|
| TX датчика | GPIO20 (RX) |
| RX датчика | GPIO21 (TX) |
| GND | GND |
| VCC | по паспорту датчика |

Скорость 256000, 8N1. Подключать только один датчик за раз: LD2401 или LD2450. Логический уровень UART — 3.3 В; не подавать 5 В на GPIO.

## Сборка Arduino IDE

1. Установить ESP32 Arduino core **3.3.12**.
2. Открыть файл `ESP32_C3_LD_Radar_3.0.13.ino` из этой папки.
3. Выбрать **ESP32C3 Dev Module**.
4. Рекомендуемые параметры: CPU 160 MHz, Flash 4 MB, USB CDC On Boot — Enabled (если используется native USB).
5. Скомпилировать и загрузить прошивку.

Дополнительные графические библиотеки не требуются. Используются встроенные SPI, Wi-Fi, WebServer и Preferences из ESP32 core.

## Функции

- Автоматическая работа с LD2401 или LD2450 по общей UART-линии.
- Полноэкранный радар для LD2450 и экран присутствия/дальности для LD2401.
- Точка доступа Wi-Fi **LD-Radar-C3**; веб-интерфейс доступен по адресу `http://192.168.4.1/`.
- Домашняя Wi-Fi сеть, журнал и CSV-экспорт.
- Фильтры дальности и задней полусферы, три цели и их шлейфы.
- Настраиваемое время шлейфа и зоны тревоги.
- DEMO-режим.

## Ограничения и проверка

- Физические кнопки и зуммер не подключены; настройки выполняются через веб-интерфейс.
- Управление яркостью отсутствует: LEDA запитана на адаптере.
- Отдельный тест прямого SPI-дисплея на этой распиновке прошёл на устройстве без мерцания. Полная сборка и совместная работа датчика, дисплея и веб-интерфейса должны быть проверены после прошивки.
