# Журнал изменений

## Версия 1.0.019
- Исправлена распиновка LD2401 строго по рабочему скетчу пользователя v1.0.004: TX датчика → GPIO27 (UART RX ESP32), RX датчика → GPIO26 (UART TX ESP32), OUT → GPIO25 (необязательный диагностический вход).
- Распиновка LD2450 оставлена прежней. Подключать только один датчик за раз, так как GPIO25/26 используются в обеих схемах.


## Версия 1.0.019
- Экран переведён в горизонтальную ориентацию 240×135 с поворотом на 90° против часовой стрелки относительно предыдущего положения (`setRotation(1)`).
- Основной экран, экран целей, присутствия, диагностики и настроек переработаны для горизонтального формата.
- Увеличен размер основных показателей для лучшей читаемости.
- Сохранены предыдущие функции выбора датчика.


## Версия 1.0.014
- Добавлен автоматический выбор используемого радара по наличию корректных кадров.
- Если обнаружен только HLK-LD2401, главный экран автоматически переключается на экран присутствия/дистанции.
- Если обнаружен HLK-LD2450, используется экран многоканального трекинга X/Y.
- В Serial Monitor добавлены сообщения `[AUTO] Selected sensor: ...`.
- В версии 1.0.014 использовался поворот на 180°; в 1.0.017 заменён на горизонтальную ориентацию.
- LD2401 и LD2450 не объединяются в общую модель целей; данные каждого датчика остаются отдельными.

## Важно
Автовыбор основан на получении корректных кадров, а не просто на электрическом подключении. Если оба датчика подключены, прошивка отдаёт приоритет LD2450; штатный сценарий — подключён только один датчик. `BAD DATA` для LD2401 может потребовать отдельной проверки скорости UART и фактического формата кадров.


## 1.0.019
- Интерфейс LD2401 переделан по образцу `ESP32_Radar_Tracker_TTGO_LD2401_1.0.004.ino`: секторная шкала 0–6 м, дуги дальности и история измерений за 60 секунд.
- Исторические точки показываются только по расстоянию на центральной линии: LD2401 не измеряет азимут и координаты X/Y.
- Статус, текущая дистанция и энергия выведены в нижнюю строку.
- Экран LD2450 и автоматический выбор единственного активного датчика сохранены.
