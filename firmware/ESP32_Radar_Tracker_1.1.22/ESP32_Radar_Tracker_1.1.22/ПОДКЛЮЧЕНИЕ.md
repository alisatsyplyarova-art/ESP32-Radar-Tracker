# Подключение TTGO T-Display и датчиков

Плата: классический ESP32 TTGO T-Display, ST7789 240×135.

| Сигнал | GPIO |
|---|---:|
| TFT MOSI / SCLK / CS / DC / RST / BL | 19 / 18 / 5 / 16 / 23 / 4 |
| B1 / B2 | 0 / 35 |
| UART RX / TX | 27 / 26 |
| LD2401 OUT (опционально) | 25 |
| Зуммер через транзистор | 32 |

## LD2401
TX датчика → GPIO27; RX датчика → GPIO26; OUT → GPIO25 (необязательно); GND → GND.

## LD2450
TX датчика → GPIO27; RX датчика → GPIO26; GND → GND.

Оба датчика используют UART1 256000 8N1. Подключать можно только один датчик одновременно. Питание проверяйте по документации конкретного модуля. Не подключайте зуммер напрямую к GPIO.
