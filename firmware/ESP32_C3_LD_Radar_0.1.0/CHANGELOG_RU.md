# Изменения C3-0.1.0
- Создан отдельный порт для ESP32-C3 SuperMini.
- Добавлен локальный профиль TFT_eSPI для ST7735 1.77" 160x128.
- Назначены GPIO дисплея по подтверждённой пользователем распиновке.
- UART LD2401/LD2450 перенесён на GPIO20/21.
- Уменьшены буферы шлейфа для экономии SRAM.
- Упрощена отрисовка под экран 160x128.
- Физические кнопки, буззер и LD2401 OUT не используются.
