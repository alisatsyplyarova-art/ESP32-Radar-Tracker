# ESP32-C3 LD-Radar 0.1.0

Первый перенос прошивки LD-Radar на **ESP32-C3 SuperMini + TFT 1.77" ST7735 160x128**.

## Подтверждённая распиновка дисплея (по данным пользователя)

| Линия | GPIO |
|---|---:|
| GND | GND |
| VCC | 3.3V |
| SCK | GPIO4 |
| SDA / MOSI | GPIO3 |
| RES | GPIO2 |
| RS / DC | GPIO1 |
| CS | GPIO0 |

Подсветка LEDA на адаптере предполагается запитанной от платы; отдельный GPIO подсветки не используется.

## UART радара

| Сигнал | ESP32-C3 |
|---|---|
| TX датчика | GPIO20 (RX) |
| RX датчика | GPIO21 (TX) |
| GND | GND |
| VCC | согласно паспорту конкретного датчика |

Скорость UART: 256000, 8N1. Подключать **только один** датчик за раз: LD2401 или LD2450.
Логический уровень UART ESP32-C3 — 3.3 В. Не подавать 5 В на GPIO.

## Сборка Arduino IDE

1. Установить ESP32 Arduino core 3.x.
2. Установить библиотеку TFT_eSPI 2.5.43.
3. Открыть `ESP32_C3_LD_Radar_0.1.0.ino`.
4. Выбрать плату **ESP32C3 Dev Module**.
5. Скопировать `TFT_eSPI_Setup_ESP32_C3_ST7735.h` в каталог `TFT_eSPI/User_Setups/` как `User_Setup_C3_ST7735.h` и в `TFT_eSPI/User_Setup_Select.h` оставить активной строку `#include <User_Setups/User_Setup_C3_ST7735.h>`. Профиль должен применяться также к исходникам самой библиотеки.
6. Частота CPU 160 MHz, Flash 4 MB, USB CDC On Boot — Enabled (если используется native USB).

## Ограничения первой сборки

- Физические кнопки и зуммер в этой аппаратной конфигурации не назначены; настройки доступны через веб-интерфейс.
- Управление яркостью через GPIO пока отсутствует (LEDA запитана на адаптере).
- ST7735 и UART распиновка заданы, но ориентация/смещение цветового таба и фактическая работа должны быть проверены на конкретной плате.
- GPIO20/21 назначены под UART датчика; убедиться, что конкретный вариант SuperMini не использует их внешним USB-UART мостом.
- Из-за меньшей SRAM C3 уменьшен буфер шлейфа по сравнению с классическим ESP32.
- Это первый порт: до проверки на физической плате не считать его аппаратно протестированным.

## Возможности

Сохранены парсеры LD2401/LD2450, общая UART-линия, Wi-Fi AP и веб-сервер, цели LD2450, фильтры дальности/задней полусферы, шлейфы и зоны тревоги.
