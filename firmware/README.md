# Firmware

Последняя опубликованная версия прошивки: [ESP32 Radar Tracker 1.1.20](ESP32_Radar_Tracker_1.1.20/ESP32_Radar_Tracker_1.1.20/).

Откройте в Arduino IDE именно папку версии 1.1.20. Все файлы .ino, .h и .cpp находятся в одной папке скетча.

Папка `ESP32_Radar_Tracker/` — прежняя базовая версия; не используйте её как актуальную без сверки версии.

См. [инструкцию сборки](../docs/BUILD_RU.md), [подключение](../docs/HARDWARE_RU.md) и [описание веб-интерфейса](../docs/WEB_INTERFACE_RU.md).
