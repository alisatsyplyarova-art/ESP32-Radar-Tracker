# ESP32 Radar Tracker 1.1.32

Основа: исходный архив 1.1.31 Arduino IDE.

Исправления:
- Убран статус BAD DATA для общего UART: байты другого протокола не считаются ошибкой датчика.
- DEMO остаётся выключенным после запуска (включается только вручную).

# ESP32 Radar Tracker 1.1.34

Основа: 1.1.33.

## Исправления
- В веб-график LD2450 передаются отдельные 60-секундные ряды расстояния для T1, T2 и T3; каждая цель рисуется своим цветом.
- Для LD2401 сохранён отдельный график одной линии расстояния.
- В API веб-интерфейса добавлены координаты истории движения каждой цели.
- На веб-радаре следы рисуются синими соединёнными сегментами под маркерами целей.
- На TTGO следы LD2450 стали соединёнными и более заметными с ограниченным затуханием.
- Длина буфера следа увеличена с 8 до 16 точек.

## Проверка
- Проверены структура исходников и синтаксис встроенного JavaScript.
- Полная компиляция Arduino IDE с ESP32 Core 3.3.12 и аппаратная проверка не выполнялись в этой среде.

## 1.1.35
- Под LD2450 добавлены компактные элементы управления: отдельный переключатель шлейфа веб-радара, показ/фильтрация целей за датчиком и масштаб 2/4/6 м.
- Настройки веб-радара сохраняются в Preferences и восстанавливаются после перезагрузки; переключатель шлейфа веб-радара не меняет следы на TFT.
- При включённой фильтрации цели с Y < 0 и их задние участки шлейфа скрываются на веб-радаре и графике; обработка датчика и TFT не меняются.
- Легенда радара теперь показывает цветные маркеры T1 (оранжевый), T2 (фиолетовый), T3 (зелёный) и синюю линию шлейфа.
- Исправлена версия в стартовом сообщении Serial: 1.1.35.


# ESP32 Radar Tracker 1.1.36

Основа: 1.1.35.

- Объединён масштаб веб-радара и дисплея TTGO: выбор 2/4/6 м в браузере меняет масштаб на обоих экранах.
- Короткое нажатие B2 на экране радара переключает общий масштаб по кругу 2 → 4 → 6 → 2 м.
- Селектор масштаба в настройках веб-интерфейса ограничен пресетами 2/4/6 м.
- Старые сохранённые значения масштаба автоматически переводятся к ближайшему пресету.
- Масштаб сохраняется в настройке устройства и восстанавливается после перезапуска.


# ESP32 Radar Tracker 1.1.38

Основа: 1.1.36.

- Исправлена отрисовка луча сканирования на веб-радаре.
- При включении «Луч сканирования» через веб-интерфейс появляется анимированный голубой луч с плавным хвостом.

## 1.1.38 — исправление луча сканирования LD2450
- Добавлена отрисовка луча в полноэкранном режиме LD2450 на дисплее TTGO (ранее луч рисовался только в старом секторном поле, которое не используется в этом режиме).
- Исправлено направление луча в веб-радаре: он проходит по передней полусфере, а не уходит за датчик в нижнюю часть canvas.
- Управление лучом использует сохранённую настройку `sweep` и синхронизируется с веб-интерфейсом.
