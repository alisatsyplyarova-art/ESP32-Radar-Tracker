# Сборка в Arduino IDE

## Требования

- LILYGO TTGO T-Display на классическом ESP32 с дисплеем ST7789 240×135.
- Arduino IDE.
- Пакет плат Espressif ESP32.
- Библиотека TFT_eSPI.

## Порядок сборки

1. Откройте основной файл `ESP32_Radar_Tracker.ino` из папки прошивки.
2. Убедитесь, что все файлы `.h` и `.cpp` находятся рядом с главным `.ino` в одной папке скетча.
3. Проверьте конфигурацию дисплея в `TFT_eSPI_Setup25_TTGO_T_Display.h` и примените её способом, предусмотренным вашей установкой TFT_eSPI.
4. В Arduino IDE выберите плату классического ESP32 и правильный COM-порт.
5. Выполните Verify/Compile. При успешной компиляции загрузите прошивку.
6. Откройте Serial Monitor и проверьте сообщения запуска.

## После загрузки

Подключитесь к точке доступа `LD-RADAR`, затем откройте `http://192.168.4.1/`.
