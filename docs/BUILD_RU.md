# Сборка ESP32 Radar Tracker 1.1.20 в Arduino IDE

## Требуется

- LILYGO TTGO T-Display на классическом ESP32, ST7789 240×135.
- Arduino IDE.
- Пакет плат Espressif ESP32 (core 3.x или совместимый).
- Библиотека TFT_eSPI от Bodmer.

## Подготовка

1. Скачайте репозиторий или папку версии 1.1.20.
2. Откройте папку `firmware/ESP32_Radar_Tracker_1.1.20/ESP32_Radar_Tracker_1.1.20/`.
3. Убедитесь, что папка скетча и главный файл называются `ESP32_Radar_Tracker_1.1.20`.
4. В Arduino IDE откройте `ESP32_Radar_Tracker_1.1.20.ino`. Все .cpp и .h должны оставаться рядом с ним.

## Настройка TFT_eSPI

1. Найдите файл `User_Setup_Select.h` в установленной библиотеке TFT_eSPI.
2. Включите конфигурацию `#include <User_Setups/TFT_eSPI_Setup25_TTGO_T_Display.h>`, отключив другие конфигурации дисплея.
3. Если файла Setup25 нет в `User_Setups`, скопируйте туда `TFT_eSPI_Setup25_TTGO_T_Display.h` из папки проекта.
4. Не включайте одновременно несколько setup-файлов TFT_eSPI.

## Параметры Arduino IDE

- Board: **ESP32 Dev Module** (классический ESP32).
- Port: COM-порт подключённой платы.
- Остальные параметры платы оставьте совместимыми с вашей ревизией TTGO T-Display.

Нажмите Verify/Compile. Только после успешной компиляции нажимайте Upload. Откройте Serial Monitor на скорости **115200** бод.

## После прошивки

1. Дождитесь запуска дисплея и точки доступа.
2. Подключитесь к Wi-Fi `LD-RADAR`.
3. Откройте `http://192.168.4.1/`.
4. Проверьте статус выбранного датчика и режим DEMO.
5. Проверьте копию TFT в веб-панели. Цветовая адаптация 1.1.20 действует только в браузере; физический экран не перекрашивается.

## Если экран чёрный

- Проверьте, что выбран правильный Setup25 в `User_Setup_Select.h`.
- Откройте Serial Monitor 115200 и перезапустите плату.
- При успешной инициализации в Serial выводится строка с активной конфигурацией TFT_eSPI и размером панели.
- Если появляется `sprite alloc failed`, проверьте свободную память и используемую плату.
- Не удерживайте B1/GPIO0 при обычном включении: эта кнопка связана с режимом загрузчика.
