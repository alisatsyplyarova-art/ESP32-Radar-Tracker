# Веб-интерфейс

1. Включите устройство и дождитесь запуска точки доступа `LD-RADAR`.
2. Подключитесь к этой Wi-Fi сети.
3. Откройте в браузере адрес `http://192.168.4.1/`.
4. Проверьте состояние датчика и текущие измерения.
5. При необходимости настройте домашний Wi-Fi и сохраните параметры.

Доступные функции согласно описанию проекта: статус датчика, расстояние/энергия сигнала, график последних 60 секунд, журнал измерений до 80 записей и экспорт CSV. Точка доступа остаётся доступной для настройки.
