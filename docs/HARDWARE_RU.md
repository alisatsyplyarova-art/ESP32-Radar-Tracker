# Оборудование и подключение — версия 1.1.20

## Плата

- LILYGO TTGO T-Display, классический ESP32.
- ST7789, 240×135, альбомная ориентация.
- TFT_eSPI setup: `TFT_eSPI_Setup25_TTGO_T_Display.h`.

## Подключение дисплея и кнопок

| Назначение | GPIO |
|---|---:|
| TFT MOSI | 19 |
| TFT SCLK | 18 |
| TFT CS | 5 |
| TFT DC | 16 |
| TFT RST | 23 |
| TFT подсветка BL | 4 |
| Кнопка B1 / BOOT | 0 |
| Кнопка B2 | 35 |
| UART RX ESP32 | 27 |
| UART TX ESP32 | 26 |
| LD2401 OUT (необязательно) | 25 |
| Выход тревоги / зуммер | 32 |

GPIO32 для зуммера использовать только через транзисторный ключ. Не подключайте нагрузку напрямую к GPIO.

## UART датчиков

LD2401 и LD2450 используют общий UART1: 256000 бод, 8N1. Одновременно подключайте только один датчик.

### HLK-LD2401

| Контакт датчика | TTGO T-Display |
|---|---|
| TX | GPIO27 (RX ESP32) |
| RX | GPIO26 (TX ESP32) |
| OUT | GPIO25 (опционально) |
| GND | GND |

Питание подключайте по документации конкретной платы LD2401.

### HLK-LD2450

| Контакт датчика | TTGO T-Display |
|---|---|
| TX | GPIO27 (RX ESP32) |
| RX | GPIO26 (TX ESP32) |
| GND | GND |

Проверьте маркировку разъёма и допустимое напряжение питания по документации именно вашей версии модуля. Не переносите питание по цвету провода без проверки.

## Различия датчиков

- LD2450 сообщает координаты X/Y и до трёх целей; знак X определяет левую/правую сторону, знак Y — перед/за датчиком согласно принятой в проекте системе координат.
- LD2401 сообщает присутствие/движение и расстояние/энергию, но не предоставляет координаты X/Y. Он не может показываться как пространственная точка на карте.
- Одновременная работа двух датчиков на общем UART не предусмотрена.
