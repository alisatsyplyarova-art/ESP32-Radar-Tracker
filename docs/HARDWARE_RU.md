# Оборудование и подключение

## Целевая плата

- LILYGO TTGO T-Display, классический ESP32.
- Дисплей ST7789, 240×135 пикселей.
- Один датчик: HLK-LD2401 **или** HLK-LD2450.

## Подключение LD2401

| Сигнал датчика | ESP32 |
|---|---|
| TX | GPIO27 (RX ESP32) |
| RX | GPIO26 (TX ESP32) |
| OUT | GPIO25 (необязательно) |
| GND | GND |

Питание подключайте в соответствии с документацией именно вашего модуля. Не подключайте два датчика одновременно.

## LD2450

Используйте распиновку из документации вашего модуля и соответствующие настройки прошивки. Не переносите распиновку LD2401 на LD2450 без проверки.

## Дисплей

Конфигурация TFT_eSPI находится в `TFT_eSPI_Setup25_TTGO_T_Display.h`. Необходимо, чтобы выбранный драйвер и GPIO соответствовали конкретной ревизии платы.
