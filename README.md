# ESP32 Radar Tracker

**Основная версия проекта: 1.1.45.** Актуальные исходники находятся в [firmware/ESP32_Radar_Tracker_1.1.45](firmware/ESP32_Radar_Tracker_1.1.45/).

Проект для LILYGO TTGO T-Display на классическом ESP32 с дисплеем ST7789 240×135 и поддержкой одного подключённого датчика HLK-LD2401 или HLK-LD2450.

## Основная версия 1.1.45

- Исправлено переполнение статической DRAM на классическом ESP32.
- Реальный и демонстрационный режимы используют общий буфер целей.
- Точки следа хранятся в компактном формате 6 байт.
- Сохранены 3000 точек на цель и история до 300 секунд.
- Сохранены исходники предыдущих версий в отдельных каталогах.

## Быстрый запуск

1. Откройте папку [прошивки 1.1.45](firmware/ESP32_Radar_Tracker_1.1.45/) в Arduino IDE.
2. Установите пакет плат Espressif ESP32 3.3.12 и библиотеку TFT_eSPI 2.5.43.
3. В настройках TFT_eSPI включите профиль `TFT_eSPI_Setup25_TTGO_T_Display.h` из папки скетча.
4. Выберите **ESP32 Dev Module** (классический ESP32), COM-порт и выполните Verify/Compile.
5. После загрузки подключитесь к Wi-Fi LD-RADAR и откройте **http://192.168.4.1/**.
