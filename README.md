# ESP32_Radar_Tracker

Прошивка для платы **LILYGO TTGO T-Display (классический ESP32, экран ST7789 240×135)** с поддержкой одного подключённого датчика: LD2401 или LD2450.

## Возможности

- Выбор масштаба: 0,5 / 1 / 1,5 / 2 / 3 / 4 / 6 м.
- Точка доступа Wi-Fi `LD-RADAR`, адрес `192.168.4.1`, без пароля.
- Веб-панель: состояние датчика, расстояние, энергия сигнала.
- График расстояния за последние 60 секунд.
- Журнал до 80 измерений и выгрузка в CSV.
- Настройка домашнего Wi-Fi с сохранением параметров; точка доступа остаётся активной.

## Подключение LD2401

- TX датчика → GPIO27 (RX ESP32).
- RX датчика → GPIO26 (TX ESP32).
- OUT → GPIO25 (необязательно).
- GND → GND.

Питание подключайте по документации именно вашего модуля. Подключайте только один датчик за раз.

## Сборка

Инструкция находится в архиве прошивки в файле `ИНСТРУКЦИЯ_ARDUINO_IDE.txt`. Требуются пакет плат ESP32 от Espressif Systems и библиотека TFT_eSPI от Bodmer.

## Веб-панель

Подключитесь к сети `LD-RADAR` и откройте http://192.168.4.1/. Подробности описаны в файле `ВЕБ_ИНТЕРФЕЙС.md` внутри архива.
