# ESP32_Radar_Tracker

Проект ESP32_Radar_Tracker для TTGO T-Display (ESP32, экран ST7789 240×135) с поддержкой радаров LD2401 и LD2450. Датчики используются по одному.

## С чего начать

- Каталог версий и статусы: [VERSIONS_RU.md](VERSIONS_RU.md)
- Подключение LD2401: TX датчика → GPIO27 (ESP32 RX2), RX датчика → GPIO26 (ESP32 TX2), OUT → GPIO25, общий GND; питание сверять с документацией конкретного модуля.
- Arduino IDE и TFT_eSPI должны быть настроены для используемой платы TTGO T-Display/ST7789.
- Для LD2401 угол цели неизвестен: датчик не выдаёт координату направления, поэтому визуализация не должна представлять направление как измеренное.

## Версии и статус проверки

По состоянию на 2026-10-30 пользователь подтвердил, что версия **1.0.019 компилируется и запускается**. Версии 1.0.021 и 1.0.022 не подтверждены компиляцией и проверкой на устройстве. Версия 1.0.020 исключена из сохраняемого набора.

## Запланированные функции

- Выбор масштаба радара: 0,5 / 1 / 1,5 / 2 / 3 / 4 / 6 м.
- При запуске точка доступа Wi-Fi `LD-RADAR`, адрес `192.168.4.1`.
- Веб-график дистанции за последние 60 секунд.
- Журнал последних 80 измерений и экспорт CSV.
- Подключение к домашнему Wi-Fi с сохранением параметров при перезапуске при сохранении доступности точки доступа.

Наличие функции в списке требований не означает, что она уже реализована или проверена в прошивке.

## Имя проекта и версии

Короткое имя проекта и базовое имя архивов: `ESP32_Radar_Tracker`. Начиная со следующей новой прошивки используется формат версии `1.1.01`, `1.1.02`, `1.1.03` и далее. Текущая рабочая прошивка сохраняет исходный номер `1.0.024`.
