# ESP32 Radar Tracker

**Основная версия проекта: 1.1.47.** Исходники: [firmware/ESP32_Radar_Tracker_1.1.47](firmware/ESP32_Radar_Tracker_1.1.47/).

Проект для LILYGO TTGO T-Display (классический ESP32, ST7789 240×135) с одним датчиком HLK-LD2401 или HLK-LD2450.

## Версия 1.1.47
- Улучшено сопровождение трёх целей LD2450: глобальное сопоставление измерений и прогноз координат по движению.
- Снижена вероятность скачков идентификаторов при сближении и перестановке целей в кадрах датчика.
- Сохранены тревожные пороги 1–6 м и четыре независимых сектора LD2450.
- Сохранены функции 1.1.46 и история следов до 300 секунд.

## Быстрый запуск
1. Откройте папку [прошивки 1.1.47](firmware/ESP32_Radar_Tracker_1.1.47/) в Arduino IDE.
2. Установите ESP32 core 3.3.12 и TFT_eSPI 2.5.43.
3. Включите профиль `TFT_eSPI_Setup25_TTGO_T_Display.h`.
4. Выберите **ESP32 Dev Module**, COM-порт и выполните Verify/Compile.
5. Подключитесь к Wi-Fi LD-RADAR и откройте http://192.168.4.1/.
