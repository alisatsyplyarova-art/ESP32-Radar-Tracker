# ESP32 Radar Tracker

**Основная версия проекта: 1.1.46.** Актуальные исходники находятся в [firmware/ESP32_Radar_Tracker_1.1.46](firmware/ESP32_Radar_Tracker_1.1.46/).

Проект для LILYGO TTGO T-Display на классическом ESP32 с дисплеем ST7789 240×135 и поддержкой одного подключённого датчика HLK-LD2401 или HLK-LD2450.

## Основная версия 1.1.46

- Выбор порога тревоги: выключено или 1, 2, 3, 4, 5 и 6 м.
- Для LD2450 тревога учитывает включённые сектора: передний центральный, левый, правый и задний.
- Для LD2401 используется радиальная тревога по расстоянию (без координат X/Y).
- При выборе большего порога тревоги фильтр дальности автоматически расширяется до выбранного расстояния, если это необходимо.
- Сохранены функции основной версии 1.1.45, включая компактную историю следов до 300 секунд.

## Быстрый запуск

1. Откройте папку [прошивки 1.1.46](firmware/ESP32_Radar_Tracker_1.1.46/) в Arduino IDE.
2. Установите пакет плат Espressif ESP32 3.3.12 и библиотеку TFT_eSPI 2.5.43.
3. В настройках TFT_eSPI включите профиль `TFT_eSPI_Setup25_TTGO_T_Display.h` из папки скетча.
4. Выберите **ESP32 Dev Module** (классический ESP32), COM-порт и выполните Verify/Compile.
5. После загрузки подключитесь к Wi-Fi LD-RADAR и откройте **http://192.168.4.1/**.
