# ESP32 Radar Tracker

**Основная версия проекта: 1.1.49.** Исходники: [firmware/ESP32_Radar_Tracker_1.1.49](firmware/ESP32_Radar_Tracker_1.1.49/). Каталог исходников соответствует номеру версии прошивки.

Проект для LILYGO TTGO T-Display (классический ESP32, ST7789 240×135) с одним датчиком HLK-LD2401 или HLK-LD2450.

## Версия 1.1.49
- Веб-фильтр дальности применяется одной атомарной командой без промежуточного возврата значений.
- На TFT LD2450 справа от полукруга радара выводятся координаты X/Y всех трёх целей.
- Сохранены обработка задней полусферы, три дорожки сопровождения, тревожные зоны 1–6 м и четыре сектора.

## Быстрый запуск
1. Откройте папку [прошивки](firmware/ESP32_Radar_Tracker_1.1.49/) в Arduino IDE.
2. Установите ESP32 core 3.3.12 и TFT_eSPI 2.5.43.
3. Включите профиль `TFT_eSPI_Setup25_TTGO_T_Display.h`.
4. Выберите **ESP32 Dev Module**, COM-порт и выполните Verify/Compile.
5. Подключитесь к Wi-Fi LD-RADAR и откройте http://192.168.4.1/.
