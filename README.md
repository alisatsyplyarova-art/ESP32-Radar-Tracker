# ESP32 Radar Tracker TTGO

Исходники проекта для Arduino IDE находятся в архиве `ESP32_Radar_Tracker_TTGO_fixed.zip`.

## Установка
1. Скачайте ZIP-архив из раздела файлов репозитория (или откройте архив в репозитории).
2. Распакуйте папку `ESP32_Radar_Tracker_TTGO_flat`.
3. Откройте `ESP32_Radar_Tracker_TTGO_flat.ino` в Arduino IDE.
4. Проверьте настройки платы, подключение датчика и библиотеки по файлу `ARDUINO_IDE.txt`.
5. Перед прошивкой сверьте распиновку с вашим вариантом TTGO и радарным модулем.

## Состояние
Это подготовленный исходный код. Прошивка не была подтверждена успешной сборкой в Arduino IDE в этой среде; соберите проект и проверьте работу на вашем оборудовании перед эксплуатацией.
