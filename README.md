# ESP32 Radar Tracker

**Текущая версия исходников: 1.1.20.** Проект для LILYGO TTGO T-Display на классическом ESP32 с дисплеем ST7789 240×135 и поддержкой одного подключённого датчика HLK-LD2401 или HLK-LD2450.

English overview: [docs/README_EN.md](docs/README_EN.md).

## Возможности прошивки 1.1.20

- TFT-интерфейс с экранами RADAR, TARGETS, PRESENCE, DUAL, DIAG и SETTINGS.
- Режимы отображения ALIEN и CLASSIC, три цветовые темы, масштаб 0,5–6 м, яркость и следы целей.
- Автоматическое определение работающего датчика: LD2450 имеет приоритет при наличии валидной связи.
- LD2450: координаты X/Y и сопровождение до трёх целей в пределах возможностей датчика.
- LD2401: присутствие/движение, доступные расстояния и энергия; координаты X/Y датчик не выдаёт.
- Общий UART1 GPIO27 (RX ESP32) / GPIO26 (TX ESP32), 256000 8N1. Подключать только один датчик.
- Wi-Fi AP **LD-RADAR**, адрес **http://192.168.4.1/**; точка доступа по умолчанию открытая.
- Веб-панель: статусы, значения датчика, график последних 60 секунд, журнал до 80 записей и CSV.
- Копия кадров TFT в веб-панели: 240×135, до 700 px на широком экране, адаптивно на телефоне, около 5 кадров/с. В 1.1.20 цвета веб-копии адаптируются к тёмно-голубой палитре страницы; физический TFT не перекрашивается.
- Настройка диапазона расстояния, зон тревоги LD2450 и внешнего зуммера.

## Быстрый запуск

1. Откройте папку [прошивки 1.1.20](firmware/ESP32_Radar_Tracker_1.1.20/ESP32_Radar_Tracker_1.1.20/) в Arduino IDE.
2. Установите пакет плат Espressif ESP32 и библиотеку TFT_eSPI от Bodmer.
3. Настройте TFT_eSPI по файлу `TFT_eSPI_Setup25_TTGO_T_Display.h` из папки скетча.
4. Выберите **ESP32 Dev Module** (классический ESP32), COM-порт и выполните Verify/Compile.
5. После загрузки откройте Serial Monitor на 115200 бод.
6. Подключитесь к Wi-Fi **LD-RADAR** и откройте **http://192.168.4.1/**.
