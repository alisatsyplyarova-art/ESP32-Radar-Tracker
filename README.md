# ESP32 Radar Tracker

**Текущая версия исходников: 1.1.30.** Проект для LILYGO TTGO T-Display на классическом ESP32 с дисплеем ST7789 240×135 и поддержкой одного подключённого датчика HLK-LD2401 или HLK-LD2450.

English overview: [docs/README_EN.md](docs/README_EN.md).

## Возможности прошивки 1.1.30

- TFT-интерфейс с радаром и экранами целей, присутствия, диагностики и настроек.
- Автоматическое определение подключённого датчика по валидным данным.
- LD2450: координаты X/Y и сопровождение до трёх целей.
- LD2401: присутствие/движение, доступные расстояния и энергия; координаты X/Y датчик не выдаёт.
- Общий UART1 GPIO27 (RX ESP32) / GPIO26 (TX ESP32), 256000 8N1. Подключать только один датчик за раз.
- Wi-Fi и веб-панель LD-RADAR: статусы, параметры датчика, график, журнал и CSV.
- Фильтр расстояния, настройки зон LD2450 и дополнительные параметры устройства.

## Быстрый запуск

1. Откройте папку [прошивки 1.1.30](firmware/ESP32_Radar_Tracker/) в Arduino IDE.
2. Установите пакет плат Espressif ESP32 3.3.12 и библиотеку TFT_eSPI 2.5.43.
3. В настройках TFT_eSPI включите профиль `TFT_eSPI_Setup25_TTGO_T_Display.h` из папки скетча.
4. Выберите **ESP32 Dev Module** (классический ESP32), COM-порт и выполните Verify/Compile.
5. После загрузки подключитесь к Wi-Fi LD-RADAR и откройте **http://192.168.4.1/**.

## Статус проверки

Исходники 1.1.30 опубликованы в GitHub. Изменения веб-радара LD2450 включают отдельные линии и цвета для трёх целей; сборка и проверка на физической плате для этой версии не подтверждены. Перед прошивкой выполните Verify/Compile.
