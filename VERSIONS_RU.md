- **1.1.03** — пользователь подтвердил, что версия работает на устройстве. Добавлены/обновлены режимы визуализации. Перед выпуском следующей версии следует выполнить чистую сборку и проверить работу на целевой плате.

## Правила версионирования

- Формат версии: `1.1.04`, `1.1.05` и далее.
- Номер версии в главном файле, `VERSION.txt`, архиве и документации должен совпадать.
- Каждое изменение прошивки сопровождается записью в журнале.
- Не отмечать сборку как проверенную, пока она не собрана и не проверена на целевой плате.

## Публикация

Архив ZIP и исходники в репозитории — разные артефакты. Для официального выпуска создайте GitHub Release с тегом версии (например, `v1.1.03`) и прикрепите архив прошивки.
