# Каталог версий ESP32_Radar_Tracker

## Текущая версия

- `ESP32_Radar_Tracker_1.1.01.zip` — русифицированы веб-панель и документация; требуется проверка компиляции после изменений.
- `ESP32_Radar_Tracker_1.0.024.zip` — подтверждена пользователем как рабочая версия; имя архива до сокращения названия проекта.

## Правила именования

Короткое имя проекта: `ESP32_Radar_Tracker`. Формат новых версий: `1.1.01`, `1.1.02`, `1.1.03` и далее. Имя ZIP-архива, папки проекта и главного файла `.ino` должно совпадать с номером версии.

## Публикация

Запись о версии в этом каталоге сама по себе не означает, что ZIP добавлен в GitHub Releases. Бинарный архив должен быть отдельно опубликован в разделе релизов.
